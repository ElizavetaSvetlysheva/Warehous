# Warehouse
Как запустить проект
Важно! Правильная настройка запуска
При открытии решения Visual Studio может назначить запускаемым проектом `WarehouseData` (библиотеку).
Чтобы запустить приложение:

1. Откройте решение `Warehouse.sln`
2. В обозревателе решений (Solution Explorer) найдите проект `Warehouse`
3. Нажмите на него правой кнопкой мыши
4. Выберите «Назначить запускаемым проектом» (Set as Startup Project)
5. Нажмите F5 или кнопку «Запустить»
